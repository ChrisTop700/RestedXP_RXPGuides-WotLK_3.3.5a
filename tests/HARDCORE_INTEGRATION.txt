Reproducibility and source evidence
----------------------------------
Current recipes: tools/data/Hardcore-Published335/.
Receipt: tools/data/Hardcore-Publication335.json.
Generation: tools/Build-HardcorePublication335.ps1 requires an explicit pinned
upstream source root and a new output directory. Committed-output validation
does not require Downloads, a workbench, a neighboring addon or a database.

The targeted Wrath pass uses 277 exact replacements across 112 chapters.

Historical source recipes remain inputs to regression tests and regeneration;
they must not be deleted merely because newer composed recipes exist.

Run the checks
--------------
  ./tools/Validate-All335.ps1 -RequireLua
Runs independent runtime, normal quest-flow and Hardcore suites with at most
three workers. Use -MaxParallel 1 for sequential execution. For a focused
check, use -Suite runtime, -Suite quest-flow or -Suite hardcore. Optional
-LuaCommand and -PythonCommand accept explicit local executable/runner paths.
No result cache substitutes for execution; failures propagate to the caller.

  ./tools/Validate-HardcorePublication335.ps1
Runs strict published-output validation. -IntegrityOnly is a diagnostic hash
check, not production-test approval. tests/hardcore-publication.ps1 rejects
corrupt, stale and foreign receipts. The combined guide check occurs here
once; the runtime suite retains syntax, lifecycle, progression and performance
tests. The full matrices retain 576 routes, 60 dungeon cases, 6,156 parsed
class/race views, 73,872 eligibility evaluations and 1,198 cached fetches.

Native Lua 5.1 is used in CI. Local Lua 5.1 runners can compile every manifest
Lua file through loadstring when a separate luac is unavailable; no runtime
dependency is added to the addon. Privacy, talent, roadmap, localization-core,
quest-header, reward, abandonment, checkpoints and Questie regressions remain.

Release archives exclude developer tools/tests through .gitattributes but
retain runtime code, assets, bundled licenses and user documentation. The
release-archive regression checks the single addon root and recursive TOC/XML
dependencies. Optional locale packaging remains separate. No test ZIP needs
to be installed: use the current addon for gameplay checks.

Gameplay checklist
------------------
Use disposable characters, initially with RXPGuides, BugGrabber and BugSack.
Do not delete real SavedVariables. Record General > Automation > "Quest auto
accept/turn in" and "Quest auto rewards"; disable the latter for manual reward
selection. Server-driven auto-accept should already be suppressed in the test
environment. Keep Ctrl released unless explicitly testing its override.

1. Fresh Orc Warrior: with Hardcore off, open the regular guide browser.
   Check Curated under Validated & Fixed Guides and Classic/TBC separately
   under Original Upstream Guides. Only eligible faction/race starts appear.
   Opening the browser/picker changes neither mode nor progress. Cancel a
   selection confirmation and verify unchanged steps, skips and checkpoints.
2. Select TBC and confirm. Test Your Place In The World (4641) from Kaltunk,
   its Gornek turn-in, then Cutting Teeth (788). Quest log and guide progress
   must agree without /reload. Test manual reward completion too. A server-
   closed dialog can require another right-click; an enabled Accept panel
   must not remain stuck. Disabled automation leaves acceptance manual.
3. Repeat Classic and Curated on disposable characters. Classic retains its
   authored Silverpine transfer; TBC retains Eversong/Ghostlands; Curated
   retains native Kalimdor progression. TBC includes Hellfire through 60;
   Classic and Curated finish in Azeroth. Do not expect identical itineraries.
4. Switch families, favorite guides and reload. Same-named chapters must keep
   separate progress/checkpoints. Test confirming and cancelling a switch to
   a softcore guide. Cancelled/expired Catch-Up, prerequisite and PartySync
   requests must not jump steps or acknowledge a guide that did not load.
5. Check Human/Night Elf, Blood Elf and Draenei starters. Human wolf credit
   follows the current objective; Monty's 6661/6662 remain usable inside the
   Tram. Blood Elves retain academy/sliver rewards and one valid Arcane
   Torrent objective. Draenei references use Jessera of Mac'Aree. Warlocks
   learn Summon Imp at an eligible, affordable trainer stop. Hunters still
   acquire first pets without obsolete tame-to-learn rank instructions.
6. Repeat key quest interactions with Questie tracking enabled and its quest
   automation disabled. Test language switching, login and repeated guide
   selection for errors, freezes or unintended progression. Report untested
   chapters honestly. Do not deliberately kill a Hardcore character.
